# 测测你是哪条上海地铁 — V5.0

2026-10-26 已通过 GitHub Pages 发布。无需登录或安装软件，两个网站可以独立更新。

## 保留的 V4.2 滚动修复

上一版每次选择答案会调用 `showQuestion()`，其内部的 `show('quiz')` 无条件执行 `window.scrollTo({top:0})`，导致页面被拉回顶部。

V4.2 修改为：
- 点击、取消选项，选项重新排序、清空重排：保留当前答题位置；不会跳到顶部。
- 点击下一题、上一题，以及开始、重新测试、进入结果页：正常定位到新页面/题目顶部。
- 点击选项时保留键盘焦点并用 `focus({preventScroll:true})` 阻止额外滚动。
- 排序条高度变化时尽量保持刚点击选项在屏幕中的位置。

其他内容全部沿用 V4.1：20 道题、排序多选规则、22 个人物结果、人物文案、权重、标题与封面。

## V5.0：最近记录与线路图鉴

完整答完20题后自动保存最近一次结果。首页可查看上次结果；完成一次即解锁全部22位角色，无需分别测出每条线路。图鉴按1—18号线、浦江线、磁浮线、市域机场线、金山铁路排列，支持详情、前后角色和返回自己的结果。

浏览图鉴、返回首页、重新测试或中途离开不会覆盖完成记录。只有再次完整完成20题并成功计算，才会替换记录。图鉴与个人结果共享角色数据和展示组件，浏览角色不会写入结果。

人物介绍、成长提醒来自原有资料；关键词仅摘录已有称号、介绍与成长提醒中的词语。本次不制作立绘、台词、关系设定或故事，也不创建空白故事页。未来可按现有稳定角色 ID 扩展共享数据和渲染器，非计分的插画/故事字段不会使记录失效。

## 本地预览与源码结构

以 GitHub main 为最新版，历史 ZIP 只是本地 V4.2 备份，不要用 ZIP 覆盖 V5。

从仓库根目录运行 `python3 -m http.server 4174 --bind 127.0.0.1`，打开 `http://127.0.0.1:4174/`。正式网站无需本机运行服务器或访客登录。

- `index.html`：原封面、原题目/角色数据、原答题样式和页面骨架。
- `assets/js/app.js`：答题状态、原计分/排序/滚动逻辑、共用结果展示及图鉴路由。
- `assets/js/records.js`：完成记录的创建、校验和本地存储容错。
- `assets/css/records.css`：新增入口、记录状态、图鉴卡片和详情布局。
- 没有框架、后端、云端同步、追踪或外部运行依赖。部署时需包含 assets 目录。

## 记录结构与恢复规则

唯一存储键：`shmetro.personality.lastResult.v1`，使用 localStorage，仅保存一个完整结果：

| 字段 | 内容 |
| --- | --- |
| schemaVersion | 数据结构版本 1 |
| testVersion | 测试版本 5.0，与原题目数据 meta.version 4.1 分开 |
| dataFingerprint | 问题、稳定角色 ID、画像与计分权重的版本指纹 |
| completedAt | 完成时的 ISO 8601 时间 |
| result | lineId、lineName、score，最终获胜角色 |
| topThree | 按原排序算法排列的前三项，每项含 lineId、lineName、score |
| answers | 20个数组，每个含1—3个选项键，数组顺序就是点击排名 |

读取时检查结构、版本、时间及20题答案，按原算法重新计算并核对线路 ID 与全部前三名得分。损坏或不兼容的数据不用于解锁，也不会因为读取失败而被主动删除。保存使用一次 setItem；不先清空旧结果，不操作其他站点功能的存储键。

所有存储访问均有异常处理。禁止存储或配额不足时仍可在当前页面完成测试、查看结果与全部图鉴，并提示无法保证下次恢复；无痕浏览结束或清理浏览器数据也可能丢失记录。不承诺跨设备恢复。

虚拟页面使用 `#/result`、`#/archive`、`#/archive/L15` 等 hash 路由，适用于现有 Pages 子路径与刷新。每次渲染受保护路由（包括直达、前进、后退）都会检查有效完成记录，而非仅隐藏入口。

## V4.2 老用户兼容的实际限制

已检查当前远程与线上 V4.2：它没有 localStorage、sessionStorage、IndexedDB 或其他持久化完成记录，答案只存在旧页面的内存中。关闭或刷新后无法安全识别旧用户；正常部署也无法读取已关闭页面的内存。因此不能自动给所有旧用户继承解锁。

最小处理是升级后完整完成一次测试，此后即可保存并一次解锁22位。仍开着的旧页面可继续查看原结果，但升级刷新不能自动带回该记录。本次没有添加自报“测过”或绕过20题的隐藏入口。

## 浏览器回归

`scripts/check-metro.cjs` 通过 Playwright 和 Chrome 实际检查桌面/触摸排序、滚动位置、20题完整流程、所有角色的结果可达性、重测和刷新。设置 `METRO_QA_URL` 可指定线上或本机地址，`METRO_QA_OUT` 指定证据输出目录；`PLAYWRIGHT_MODULE` 与 `CHROME_PATH` 可指定已有测试工具。测试工具不参与网站运行。报告与截图默认位于已忽略的 `test-results/metro/`。


`scripts/check-records.cjs` 检查 V5 的真实20题保存、刷新、实际关闭并重开 Chrome、重测覆盖规则、22位图鉴、直达与历史导航、存储损坏/权限/配额、无痕上下文，以及150组答案对原 Git 历史中 V4.2 算法的逐项比较。通过 `RECORDS_QA_OUT` 指定证据目录，其余工具环境变量与旧脚本一致。原有 `MetroQuizV4` 测试 API 保留用于回归，不提供产品解锁捷径。
